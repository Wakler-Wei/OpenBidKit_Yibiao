# 公司内部版设计输入

日期：2026-11-18。状态：方向初稿，尚未选定正式界面。

- 使用者：公司内部投标人员；Windows 桌面优先。
- 产品边界：用户自行配置第三方 Key，不建设公司统一充值、余额、账户计费后台。
- 共同场景：设置 → 文本模型。三稿均展示服务商、服务地址、API Key、模型名称、模型参数和保存反馈，不引入新业务功能。
- 预览名称：“投标工作台”仅为暂名；公司中文全称、正式产品名待确认。Logo 使用用户图片，不重画。
- 同一画布：1440×900；另检查 375×812 的预览适配。桌面壳层内滚动。
- 域名与服务部署暂不处理；这不代表现有作者在线服务已完成独立。
- 此轮产出：独立本地分支、素材清单、三个可点击初稿和六候选总览。未更改 client 业务代码。
- 初稿为本地静态演示，无模型请求、无真实连通测试、无 Key 持久化；所有提示明确标记演示。

设计约束：沿用现有中文系统字体、全局 CSS 和设置字段语义；正式实现继续使用 React + Radix。正文至少 14px，移动预览 16px；标签至少 12px，交互目标至少 44px，键盘焦点可见。红色来自用户标识；区分品牌红与错误状态的文字含义。

UI/UX Pro Max 检索：`enterprise productivity desktop settings --design-system` 返回 Minimalism & Swiss Style，适用于企业工具；其单列营销页结构与本项目不符，未采纳。采用清晰网格、低装饰、可见标签、字段旁帮助、焦点反馈；保留项目现有系统字体而不加载网络字体。补充 `visible field labels helper text --domain ux` 的 Input Labels 规则。

五问：页面承担模型接入配置；近距离长期办公；理性克制；四个必填业务字段加折叠参数；以“服务接入到文档生成”的工作关系组织界面。主角素材为用户真实 Logo 与可操作配置面板，不需要营销插画。
