## 设计与来源说明

这是一份**几何矢量重建稿**：VP 使用连贯圆角路径；HONOR 使用近似原图的几何笔画与椭圆；中文按用户确认的“微品致远”重新排版并转路径。不是对原始图做简单放大，也不是原公司的原始矢量文件。轮廓、字距、笔画端点与原图存在差别，请在确认页核对。

用户指出原标识第一个 O 右上有小红点后，已在横版深浅底 SVG 与高清 PNG 中补回对应红色角标；补充参考图保存为 `reference-logo-detail.png`。VP独立图标不包含HONOR字标，因此不添加该角标。

中文由本机 Microsoft YaHei 的四字轮廓转换为路径，文件不嵌入或分发字体文件。所有SVG没有字体依赖、外链图片或base64位图，可以在矢量编辑器中调整。横版适度重排下方细线与中文，避免低清文字描摹后变形。

- 图形红：浅底 `#ee2b55`；深底适配红 `#ff5477`。均为本次重建建议色，不冒称既有公司标准色。
- 字标：浅底 `#18191c`；深底 `#ffffff`。
- 产品主操作延续 A 方向的较深红 `#c51f45`，作为界面功能色，与Logo红分工。
- 应用图标不放 HONOR 与中文，避免16/24px不可读；保留VP以关联公司品牌。
- 横版建议可见宽度不少于160px，过小场景改用VP图形；不拉伸，不给横版额外加滤镜。
- 现阶段未导出ICNS、未修改安装包、未替换client资产；本轮交付以Windows为主。

## 可复现制作

1. Windows PowerShell **7**：`pwsh -NoProfile -File build-assets.ps1` 生成SVG（PowerShell 5默认读取无BOM UTF-8时会有中文问题，不用于此脚本）。
2. 使用Chromium加载每份独立SVG，按指定画布截图，背景透明：横版2400×692、VP和应用图标1024×1024；PNG写入 `png/`。浏览器渲染时使用 `omitBackground: true`，不可截入浏览器栏。
3. `pwsh -NoProfile -File build-assets.ps1 -Finish` 从1024px母版缩采样并生成ICO。

生成脚本写入的文件都在本目录。源代码 `client/` 尚未采用这些素材；等待用户确认后才应用。
