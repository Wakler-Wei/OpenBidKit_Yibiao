# 微品致远投标工作台 1.0.0 内部试用版

- 日期：2026-11-18。
- 分支：`codex/company-internal`。
- 版本标签：`company-v1.0.0-20261118`（公司版本独立编号，不代表原项目的版本号）。
- 适用平台：Windows x64；人工分发，不启用作者客户端自动更新。
- 安装包：`WeiPinBid-1.0.0-20261118-win-x64.exe`；同名 ZIP 为解压运行版。

## 本版改动

- 接入用户确认的 VP / HONOR / 微品致远品牌、横版 Logo 和 Windows 图标，产品名改为“微品致远投标工作台”。
- 默认由员工配置第三方模型服务的 API Key；移除作者账户、官方 API 推广及充值界面。
- 独立应用标识 `com.weipin.bidworkbench`，独立数据目录 `%APPDATA%\weipin-bid-workbench`，不迁移或覆盖原易标数据。
- 停用作者自动更新、自动公告及广告展示，清理打赏、赞助、求 Star 和原作者支持入口；保留开源许可与归属说明。
- 内部发行无需作者激活，不伪造作者认证或构建签名。
- Agent 失败诊断脱敏后留在本机，设置 → 通用中可查看、手动导出给内部管理员，不自动上传作者诊断服务。诊断包仍可能包含业务正文，导出前应核对。
- 公司内部版启动 IP 查询固定按空名单处理，不请求作者封禁接口，不因其名单结束客户端进程。Worker 黑名单、服务端过滤和普通统计保留。
- 补齐自包含 Word/Open XML 助手，新增缺少助手即中止打包的检查，修复此前检查包中模板预览或应用失败的问题。

## 同事试用

1. 运行 EXE 安装，或将 ZIP 完整解压后运行目录内的 EXE；不要只复制解压目录中的主程序。
2. 在设置中配置自己的文本模型服务地址、API Key、模型名称并测试连接；需要生图时另配生图服务。
3. 先用非敏感样例检查模板预览、复制/编辑/选用，再测试导入、解析、目录、正文与 Word 导出。模型调用费用由所配置的服务商收取。
4. 遇到问题记录操作步骤、截图和时间；Agent 失败时可从设置中手动导出诊断包给内部管理员。

## 验证边界与后续事项

- 公司配置、人工更新、内部发行、打赏停用、诊断本地留存与导出已有专项验证；三套系统模板已验证真实 Word 样张、选用、保存及重启恢复。
- 未执行真实付费模型的完整标书生成与整本导出验收，需本次同事试用确认。
- 插件市场、OCR 组件下载、模型信息、精选资源及原项目更新日志仍可能依赖作者服务；普通匿名统计保留。本版本不是完全离线版，未部署公司服务端。
- 尚未接入 Windows 系统代码签名；本次不提供 macOS 安装包。
- Git 标签采用 `company-` 前缀，避免触发原仓库 `v*` 标签的自动 Release 流程；本次只提交公司分支与标签，不发布 GitHub Release。
